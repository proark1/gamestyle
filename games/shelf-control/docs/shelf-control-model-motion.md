# Shelf Control shared characters and continuous movement

Shelf Control now calls the shared worker factory used by the farmer and delivery crew. All mannequins use that exact mesh geometry, limb pivots and proportions, with an identical wood material treatment. The guard uses the shared worker with a badge and flashlight. Character materials are cloned per instance so recoloring or disposing a mannequin cannot affect other players or games.

Previously, every render frame moved 35–40% of the way to the newest network position. The character would approach that position, nearly stop, then move again on the next response. The guard's walk animation also stopped when it caught up to each packet. Movement now advances locally every frame using the same speeds and shelf collisions as the server. Request timing and acknowledged input allow bounded reconciliation; key release is immediate, and an older reply cannot restart walking. The camera and held equipment follow the same rendered body. Visible remote actors use a timestamped interpolation buffer and disappear as soon as the latest private snapshot revokes their visibility.

Movement requests are coalesced with at most one movement poll in flight. Input changes wake an idle connection immediately. Scene input remains paused outside a round, while the previously fixed lobby buttons remain enabled. Held movement survives the hiding-to-playing transition. The visibility mesh reuses its vertex buffer rather than allocating and disposing a geometry on every network reply.

Validation: all 511 release tests pass, including 42 Shelf Control tests covering exact shared mesh/pivot/material comparisons, 30/60/144 Hz walking with irregular 90–230ms replies, immediate stop and stale replies, collisions, hiding/stun/capture/disconnection, privacy removal, NPC routes and host controls. TypeScript, focused lint and the Railway production build pass. A check against the local production server with 70–160ms delayed replies measured continuous walking at 3.07–3.23 units/second (target 3.1), with less than 0.008 units of correction after release. Browser checks verified Add NPC, fill/start, three NPC escapes, round rotation and the shared character proportions in the player view, with no console errors.
