# Shelf Control

Extension approved 8 September 2026: the four seats support one to four humans plus invited NPCs. See `shelf-control-bots-design.md` for host seat controls, cooperative escape behaviour and a guard limited to observed evidence.

Approved direction: a separate four-player furniture-store stealth game in Jumbleyard. Exactly one guard and three player mannequins among eighteen identical-looking showroom figures. Guard assignment rotates each round.

The first fifteen seconds let mannequins hide while the guard waits in the office. A three-minute hunt follows. Furniture blocks movement and sight. The guard has a forward viewing area and a small nearby area, both blocked by shelving. Snapshots contain only locally visible characters/items and visible nearby action sounds. No hidden ownership, NPC routines, starting positions, item carriers outside view or offscreen action notifications reach the guard. The server simulates the room, including when the guard is lobby host. Captured/escaped players see a waiting screen rather than an unrestricted spectator camera.

Mannequins pose with Space, move with WASD/arrows or touch, interact with E and drop with Q. NPCs use identical figures and poses, occasionally walking and rearranging props. Two keys open the loading door; a ladder offers a service-hatch route. Both routes require the security switch to be off. Witnessed theft remains useful evidence. Five wrong inspections end the hunt; successful catches do not spend a mistake. Inspection requires proximity and line of sight, and has a cooldown. The mannequin team wins if at least one escapes by the round's end; the guard wins if all are caught or no one escapes before time runs out.

Use persistent server rooms in a separate `shelf:` namespace, authenticated membership, atomic updates, ordered input and idempotent actions. Start requires exactly four people. A departure cancels the active round and returns everyone to the lobby; the next player becomes host if necessary. Refresh restores the local session without exposing other players' identities. Blend Business and existing games remain separate.

Visual direction: cobalt store shelving (#234d9b), midnight uniforms (#152642), tangerine accents (#f58b39), oak floor (#b78b56), ivory mannequins (#eadfc8), pale blue UI (#edf3ff). Existing Fredoka display and DM Sans body typography. A large local 3D showroom is the working surface, with a compact shift clock, role instructions and keyboard/touch actions. The hiding phase uses a closed-office overlay. Identical mannequins have exaggerated artist-dummy poses; only the local mannequin has a private selection marker. Existing material recordings provide restrained footsteps, ladder, key and switch Foley; farm animal sounds and farm narration are not used.
