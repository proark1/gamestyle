# Mobile pasture UI

The pasture is the primary surface. On phones and touch tablets, replace the persistent objective/herd/roster cards with an on-demand Plan dialog. One header contains the role, timer, Plan and menu. A quiet status line shows exposure/visibility and objective progress. The room code and settings move into the menu. Voice stays mounted when the menu closes.

Keep movement under the left thumb and contextual actions under the right thumb. Hide Drop until carrying something; remove keyboard instructions and idle hints from touch play. Event notices expire during active rounds. Preserve full details, help, invitations and leave confirmation. The round continues when details are open, but player input is cleared.

Use the existing pasture palette (ink #294a43, cream #fff7e1, sage #829770, gold #f3bf50, warning #ad623f), Fredoka for the timer/headings, and DM Sans for controls. Controls remain at least 44px. Respect dynamic viewport height, safe areas, small landscape screens, focus navigation and reduced motion. Lobby and dialogs use their available height rather than stacking over unrelated HUD panels.

Scope stays inside Act Natural; preserve other games and the current live release. Validate contextual actions, source checks and the production build before publishing. Browser testing has not been requested.
