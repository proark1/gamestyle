# Jumbleyard logo ideas, round two

These three concepts respond to the request for a simpler, cooler party-game mark. They use transparent SVGs, small color accents, and the existing site background for the comparison. Each has a light and dark wordmark plus a standalone mark. The mark SVGs are compact and contain no font data.

| Direction | Colors | Character |
| --- | --- | --- |
| Jolt J | Coral and aqua | Cleanest, with a recognizable initial |
| Jumble Burst | Violet and coral-orange | Most energetic and chaotic |
| Chaos Grin | Cobalt and pink | Friendliest and most characterful |

The wordmarks use the site’s Fredoka or DM Sans fonts. Their text is embedded in the SVGs for consistent rendering outside the app. `compare.html` and `compare.png` show the logos on the site’s light gradient and dark header color, with their marks at 32 px.

Run `node docs/brand/logo-round-2/generate.mjs` from the repository root to regenerate the SVGs and comparison page.
