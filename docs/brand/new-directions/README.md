# Three new Jumbleyard identity directions

[Comparison board](compare.png) shows the three original directions. **The Host** is selected. See the [applied preview](host-selected.png) for its landing header and icon sizes.

## The Host

A face-led mascot built from the game's sculpted clay character style. The raised brow and open laugh carry the party energy, while the wordmark stays quiet. The selected transparent head is `public/images/brand/host-head.png`. Browser, PWA, iOS, and Android icons are exported from that source with `node scripts/export-host-icons.mjs`.

## Chain Reaction

Four game pieces tip into each other, showing how one player can set off the whole group. The icon is a flat SVG (`chain-reaction.svg`) with four controlled colors and no gamepad or confetti.

## Type Crash

A typographic identity led by the full name. One letter breaks the wordmark's grid; the compact `J` icon repeats the displacement (`type-crash.svg`). This is the most restrained route.

The avatar is the most directly tied to the current Jumbleyard art. Chain Reaction expresses physical party chaos without a mascot. Type Crash depends on typography and can travel farthest beyond the current game art style.
