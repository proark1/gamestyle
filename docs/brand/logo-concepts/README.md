# Jumbleyard logo exploration

Three vector directions use the existing Fredoka typeface and Jumbleyard colors.
The SVGs embed the font so the wordmarks render consistently outside the app.

| Direction | Idea | Strength | Tradeoff |
| --- | --- | --- | --- |
| 01 Tumble J | A playful letter tile | Clear at icon size and closest to the current brand | Less emphasis on the group-play theme |
| 02 Crew Spark | Four game pieces around a shared center | Expresses players coming together | More detail at very small sizes |
| 03 Yard Sign | Stacked wordmark and JY badge | Most character in large placements | Needs more vertical room |

This is the first exploration round. Feedback called for a simpler mark and a fresh color direction; see `../logo-round-2/` for the next set.

Open `compare.html` or `compare.png` to see all three on light and dark backgrounds. Each direction has a full lockup and a standalone mark in both color contexts.
