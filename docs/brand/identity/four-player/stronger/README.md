# Option 3 / stronger color

[Comparison preview](compare.png) of three full-color treatments for the selected J/Y gesture and multicolor wordmark. Each is shown on the landing palette beside the current game artwork, plus at 52 px and 32 px.

| Version | Blue | Red | Teal/cyan | Yellow |
| --- | --- | --- | --- | --- |
| 01 Sunlit pop | `#2469C2` | `#E54E43` | `#079CA0` | `#F1B02A` |
| 02 Arcade | `#504CE0` | `#EF405A` | `#05A8BF` | `#F6C42A` |
| 03 Poster ink | `#145F9B` | `#D5413D` | `#07827E` | `#DFA01C` |

The yellow color region now covers the full left arm of the Y until the center junction. Blue starts below that junction on the central stem. The wordmark uses darker versions of each hue to stay readable against the pale blue landing background.

These are concept assets in this folder. The production logo and favicon still use the earlier single-color direction while the color treatment is being selected.
