# Compact J/Y icon studies

[Comparison board](compare.png) tests three ways to shorten the combined J/Y mark while retaining four player colors. The mark is shown beside the multicolor wordmark and at 64, 32 and 24 px.

1. **Wide flow:** the chosen brush gesture widened 8% and shortened 16%.
2. **Tight flow:** the chosen brush gesture widened 12% and shortened 25%.
3. **Compact redraw:** shorter center stem, thicker branches and a rounder J hook. This has the best read at 24 px.

The board uses the **Arcade** palette from the preceding color study so geometry can be compared under one consistent color treatment. It is a design preview; the current production mark has not been replaced.
